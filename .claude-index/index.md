## Project Overview

- **Type:** Desktop application (Electron) + CLI, single package — not a monorepo
- **Languages:** JavaScript 100% (ESM, `"type": "module"`), plus 1 HTML file and 1 CSS file
- **Stack:** Electron ^45.2.3, Node >=22, esbuild ^0.28.2 (CLI bundle), electron-builder ^26.18.0 (Windows x64 NSIS + portable)
- **Tests:** `node --test "test/*.test.mjs"` (13 suites, 122 top-level tests) + a real-app smoke suite
- **Size:** 68 source files, ~16,575 lines (largest: `bin/aragon-browser.cjs` 1,964 — generated; hand-written largest: `src/kernel/browser-kernel.js` 1,256)
- **What it is:** a browser that an AI agent drives by *writing JavaScript*. The agent gets a
  structured accessibility snapshot with stable `@N` refs plus real CDP pointer input, instead of
  screenshots and guessed coordinates. No Chromium source is patched — the work happens at five
  "engine boundary" seams on top of the Electron binary.
- **Entry points:** `src/main/main.js` (Electron app, via `package.json` `main`),
  `src/cli/index.js` (CLI, bundled to `bin/aragon-browser.cjs` and exposed as the
  `aragon-browser` bin), `src/renderer/index.html` (UI chrome)

## Architecture at a glance

```
agent script (JS on stdin)
  -> src/cli/            client: injects helpers, executes the script, sweeps tabs
       | NDJSON + per-launch token over 127.0.0.1:<random port>  (runtime.json coordinates)
  -> src/kernel/         server: one RPC method table, 'agent' surface vs 'ui.*' surface
       | electron IPC, renderer may only call ui.* methods
  -> src/renderer/       frameless shell: self-drawn titlebar / sidebar / tab strip / address bar
```

Pure, Electron-free modules (marked below) carry the semantics worth testing and are covered by
plain `node --test`: `locator.js`, `ax-snapshot.js`, `ref-registry.js`, `cli/tab-cleanup.js`,
`shared/*`, `main/space-scope.js`, `main/window-controls.js`.

## Feature Map

### Kernel control plane (`src/kernel/`)
Entry: `src/kernel/browser-kernel.js`
- Single RPC method table for both surfaces; routes calls, orchestrates per-frame AX capture and
  `@N` ref assignment. The one place where "what the browser can do" is enumerated.
- **Key exports:**
  - `BrowserKernel({ version, learningRoot })` — kernel instance
  - `dispatch(method, params, { surface })` — method router (`agent` | `ui`); the `ui.*` table is
    the renderer's only reach, gated by `AGENT_UI_ALLOWLIST` for agent-side captures
  - `captureSnapshot(space, options)` — multi-frame AX snapshot
  - `attach(transport)` / `shutdown()`
- `src/kernel/task-spaces.js` — `TaskSpaceManager({ onStateChange })`: one `BrowserWindow`, spaces
  as groups of `WebContentsView`; `create`, `createTab`, `requireAgentControl`, `handOff`,
  `normalizeUrl`. Visibility is *derived* (off-window placement), never `setVisible(false)` —
  Chromium drops real input to hidden pages.
- `src/kernel/cdp-channel.js` — `CdpChannel(webContents, label)`, `ROOT_SESSION`, `send`,
  `settleChildSessions`, `frameOwnerBackendId`, `waitForEvent`: per-tab debugger session, OOPIF
  session topology, bounded event ring, dialog policy.
- `src/kernel/runtime-transport.js` — `RuntimeTransport({ handler, runtimeFile, metadata })`,
  `listen`, `close`, `readRuntimeCoordinates`, `isProcessAlive`: loopback NDJSON server with a
  per-launch token, publishes `runtime.json`.

### AX snapshot & `@N` ref stability (`src/kernel/`)
Entry: `src/kernel/ax-snapshot.js`
- Pure functions that turn raw `Accessibility.getFullAXTree` payloads from several sessions into
  one compact text: presentation folded, duplicate text merged, only actionable nodes get a ref,
  OOPIF frames spliced back at their real `<iframe>` owner.
- **Key exports:** `buildSnapshot({ frames }, { maxDepth, interactiveOnly, assignRef })`,
  `normalizeRole(node)`
- `src/kernel/ref-registry.js` — `RefRegistry()`, `assign`, `absorb`, `resolve(ref, loaderBySession)`,
  `invalidateSession(sessionId, loaderId)`, `parseRef(ref)`: refs keyed by
  (session, backendNodeId, loaderId); a ref from an older document is rejected as stale.

### Locator resolution & real input (`src/kernel/`)
Entry: `src/kernel/element-resolver.js`
- Parse an agent target, find the owning session and match count, then dispatch *trusted* CDP
  mouse/keyboard events at coordinates corrected for accumulated iframe offsets.
- `src/kernel/locator.js` (pure) — `parseLocator`, `parseLocatorOrThrow`, `parseRefId`,
  `describeLocator`, `buildLocatorFindJs` / `buildLocatorCountJs` / `buildLocatorRectJs`,
  `classifyMatchCount`, `ElementResolutionError`, `ROLE_ALIASES`: target grammar
  (`@N`, css, role/text/href, xpath, `>> nth=N`, shadow piercing) and transient-vs-permanent
  classification.
- `src/kernel/element-resolver.js` — `ElementResolver(channel)`, `resolve(target, { registry, purpose })`,
  `waitFor(target, { timeoutMs, intervalMs })`: runtime half — which session owns the match, how
  many hits, and which retry kind a failure deserves.
- `src/kernel/actions.js` — `pointFor`, `clickRef`, `hoverRef`, `fillRef`, `pressKey`, `typeText`,
  `scrollPage`, `measureRect`, `sessionOffset`: real `Input.dispatch*` input.
- `src/kernel/interactions.js` — `setFiles`, `writeClipboard`, `readClipboard`, `dragBetween`,
  `doubleClickAt`, `rightClickAt`: the non-click interactions.
- `src/kernel/waits.js` — `waitForTarget`, `waitForExpression`, `waitForText`, `waitForLoad`,
  `waitForNavigation`, `waitForNetworkIdle`, `waitForDialog`, `retryOnTransient`: retries only
  *transient* failures, reads navigation state off channel events rather than round trips.

## Conventions & gotchas

1. **`bin/aragon-browser.cjs` is generated.** Edit `src/cli/index.js` and run `npm run build:cli`.
   `release.test.mjs` / `skill-package.test.mjs` will catch drift.
2. **Pure vs Electron-bound is a design contract.** `locator.js`, `ax-snapshot.js`,
   `ref-registry.js`, `shared/*`, `cli/tab-cleanup.js`, `main/space-scope.js`,
   `main/window-controls.js` must stay Electron-free so `node --test` covers the semantics.
3. **Refs die with the document.** `@N` is keyed on (session, backendNodeId, loaderId);
   a navigation invalidates them. Frames that cannot be attributed are reported, never dropped.
4. **transient vs permanent** is the most invertible rule in the codebase: 0 matches → transient,
   >1 matches → permanent, syntax error / stale ref / cross-document → permanent. `page.waitFor`
   retries only transient.
5. **Hidden pages get no real input.** Tab visibility is derived by moving views off-window;
   `setVisible(false)` would break agent clicks. `activeTab()` pulls a space to the front before
   acting on it.
6. **Only `.win-controls` may be `no-drag`** in the titlebar (asserted by `test/titlebar.test.mjs`);
   `pageBounds().y` must clear the 34px titlebar or the page view covers it.
7. **The renderer may only call `ui.*`**; the agent surface may only reach
